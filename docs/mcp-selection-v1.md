# Travel Planner V1 MCP 选型清单

初次选型：2026-11-01。本文确定需要的 MCP 及职责；后续按用户要求补充高德本机接入工具。其余候选仍处于选型阶段；选型不代表业务验收通过。最新证据范围见 [能力验证记录](capability-verification-v1.md)。

## 推荐组合

| 角色 | 选定候选 | 覆盖需求 | 边界与当前证据 |
| --- | --- | --- | --- |
| 地图主服务 | [高德官方 MCP](https://lbs.amap.com/api/mcp-server/gettingstarted) | 地点/周边、驾车/步行/公交、距离、天气，支持住宿与活动的地理规划 | npm 0.0.8 协议实测 12 工具；用户本机 v4 截图显示限定的杭州地点、驾车/步行及近期天气检查通过，配置写入和 Codex 加载待确认；POI 不是酒店/租车库存，充电站位置不是实时可用性 |
| 铁路 | [Joooook/12306-mcp](https://github.com/Joooook/12306-mcp) | 车站、车次、余票、经停与中转；支撑高铁和自驾比较 | 社区项目，不是铁路官方 MCP；0.3.10 在云端被 CONNECT 代理 403 阻断初始化，本机业务仍待验收 |
| 酒店数据 | [RollingGo Hotel MCP 中国版](https://github.com/RollingGo-AI/RollingGo-hotel-MCP-CN) | 酒店搜索、房型/套餐、价格与取消政策的候选数据源 | 选为酒店首选试验候选，尚未连接；仅取 searchHotels/getHotelDetail/getHotelSearchTags 等查询能力，不接交易闭环；实际国内品牌覆盖、房型、税费及价格完整性仍待验 |
| 网页核验与缺口补充 | [Microsoft Playwright MCP](https://github.com/microsoft/playwright-mcp) | 浏览官方酒店、租车、景区等页面，核验接口未覆盖的条件和来源 | 官方通用浏览器工具，尚未在本项目实测；限定于信息查询，不下单/支付/取消。网站可访问性、登录和可提取字段依实际页面决定，不能保证租车数据可自动取得 |
| 搜索与资料提取（条件加入） | [Tavily MCP](https://docs.tavily.com/documentation/mcp) | 目的地研究、景区公告、特色餐饮、道路/天气风险及官方页面检索 | 已核实官方 Search/Extract 等工具文档，未连接；本机 Codex 原生网页搜索够用时跳过，不重复增加搜索服务；搜索结果不能替代报价或库存核验 |

**默认筹备前四项；第五项只在原生搜索不足时加入。** 其中酒店与浏览器是本轮新增的文档选型，不能追记为此前协议测试已通过。

RollingGo [工具参考](https://rollinggo.store/docs/mcp-docs/mcp-tool-reference/) 明确指出搜索列表的 price 仅是首夜展示参考价，不能直接作为全程房费。需进一步验证房型/套餐返回是否足以计算一间双人大床房的实际晚数与强制费用；华住会员价也不能假设由第三方供应链覆盖。价格确认/锁价及订单、支付工具不纳入 V1 查询工具集合。

## 完整需求覆盖与缺口

| 需求 | 使用能力 |
| --- | --- |
| 目的地推荐、方案研究 | Codex + 原生搜索或 Tavily + 高德 |
| 高铁/全程自驾/高铁租车比较 | 12306 + 高德 + 本地预算/时间计算；租车报价需网页或用户资料 |
| 酒店、双人大床房、退改与预算 | RollingGo 候选查询 + 官方页面/华住页面核验，未知价继续规划 |
| 自动挡、双驾驶员、异地还车、保险服务费 | Playwright 浏览供应商页面或用户提供资料；尚未选出经充分验证的境内专用租车 MCP |
| 景点开放、预约、门票与地方餐饮 | 高德定位 + 搜索发现 + Playwright 读取实际官方规则/页面 |
| 充电/加油、休息与停车 | 高德查地点/路线；兼容性、服务状态、实时空闲、费用和备用点另核实，暂无已验证专用充电 MCP |
| 天气与风险 | 高德实际覆盖日期的天气 + 官方公告检索，不外推预报范围 |
| 导航入口 | 另验地图实际工具或官方 URI；不能由已有 npm 工具列表推断专属地图生成已支持 |
| 偏好、版本、预算、锁定、Markdown | 已有本地 Python 核心，不需要额外 MCP |
| Word/PDF、网站及监控 | 后续版本；本轮不为这些需求增加 MCP |

## 备用与不选择

- [百度官方地图 MCP](https://lbsyun.baidu.com/docs/ai?title=mcpserver/quickstart)：地图备用，不与高德同时作为默认路线源；已有 10 工具协议测试，真实业务待验。
- [Booking.com 官方 MCP](https://developers.booking.com/mcp-server/docs/implementation-guide)：合作方授权门槛及国内覆盖需验证，暂不作为情侣境内旅行首选酒店/租车源。
- 华住会员价、境内租车双驾驶员/异地条件、充电桩实时状态：保留能力缺口，不把同名抓取项目、平台接口或旅游示例数据库视为可靠 MCP。
- 不额外引入 Filesystem、Memory、Git、数据库、Word/PDF、地图备份全家桶或交易 MCP；这些不属于当前外部查询缺口，或已有本地实现。

后续验证依次确认：连接/工具发现 → 匿名公共地点和实际日期业务查询 → 字段完整性及来源 → 与 Trip/Quote/Route 的规范化映射。没有通过对应层级，就保持 unknown/待核实。
