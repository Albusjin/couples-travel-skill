# Travel Planner V1 MCP 选型与职责

2026-11-02 按本机已部署服务调整。日常执行以 [Skill 路由配置](../skills/travel-planner/config/mcp-routing.toml)、[调用指南](../skills/travel-planner/references/mcp-usage.md) 和当前聊天实际工具为准；公共文件不含凭证或本机绝对启动路径。选型、工具可见性和实际业务验收分别记录。

## 当前组合

| 角色 | 已部署服务 | 调用时机与边界 |
| --- | --- | --- |
| 地图/天气 | 高德官方 HTTP，travel_amap | 地点/周边、关键 POI 详情、驾车/步行/公交/距离和近期天气；地图不提供酒店库存、租车资格、实时充电空闲或景区预约确认 |
| 铁路 | Joooook/12306-mcp 0.3.10，本机 stdio，travel_rail | 具体站码、目标日直达、按需中转/经停；社区封装，须过滤实际站点及本段日期，余票是快照 |
| 市内/接驳打车 | 滴滴 HTTP，travel_didi | 地点检索→taxi_estimate，两人一车、单程计一次；当前估价，未保证未来费用或接单 |
| 酒店 | RollingGo 中国版 HTTP，travel_hotel | 标签→搜索初筛→入围酒店详情；明确日期、房期、双人一间大床、具体套餐/费用/退改，isOnRequest 不作确认库存 |
| 景点规则/缺口核验 | 已有原生搜索与浏览器 | 景区官网/预约公告、酒店及租车官方页面；不是新增 MCP，不自动下单 |

高德已有限定杭州真实查询，铁路已有直达及指定中转真实查询，酒店已有指定杭州房期搜索/详情。滴滴本轮仅核对工具契约；具体城市、时段与字段仍随查询验收。详情见 [能力记录](capability-verification-v1.md)。

## 尚需补充的数据

| 缺口 | 当前处理 |
| --- | --- |
| 景点开放、临时公告、预约、门票及票种退改 | 高德定位＋景区官方页面；区分景区、实际入口和票务商品。未配置可靠专用票务 MCP，不伪造报价/预约状态 |
| 自动挡、两驾驶员资格、保险、异地还车、取还车营业时间与总价 | 租车供应商官方渠道或用户资料逐项核验；未选定专用 MCP |
| 华住个人会员价 | 华住官方渠道；RollingGo 品牌/套餐不等于本人会员权益 |
| 充电兼容、实时空闲、运营状态与费用 | 地图只提供地点，运营商官方渠道另验；保留备用点 |
| 超出预报覆盖的天气及灾害预警 | 天气待临近复核，危险天气/关闭等使用官方公告，不外推高德日期 |
| 导航入口 | 按实际可用工具或官方链接能力另验，不从已开放工具推断支持创建专属地图 |

## 暂不增加

travel_meituan 当前停用，不自动加入酒店或票务兜底。截图或同名项目不足以证明其来源、官方授权和数据完整性；后续选定实际供应商再讨论。

百度为地图备用；Booking 合作方授权不作为当前默认；Playwright、Tavily、Firecrawl 等在已有搜索/浏览器无法完成任务时再评估。当前无需同时安装多套浏览器、搜索、Filesystem、Memory 或数据库 MCP。偏好、版本、预算和 Markdown 已由本地核心完成；Word/PDF、网站、监控及交易不属于本轮 MCP 调整。

服务连接和迁移见 [接入指南](../skills/travel-planner/references/mcp-setup.md)。跨设备不复制凭证或绝对路径；config/mcp-servers.toml 仍是高德/铁路便携安装模板，不是当前四服务部署导出。
