## 新能力真实验证模板

每个供应商与能力分别记录以下内容，不保存凭证、证件、完整订单或个人健康背景：

- 能力/供应商、测试日期、实际 Desktop/云环境及调用方式。
- 匿名化输入条件、真实结果摘要、原始来源入口和查询时间。
- 覆盖字段/地区/日期范围、时效或明确有效期、库存保证的限制。
- 是否收费、账户/独立授权要求、数据来源的合法可靠性及操作边界。
- 实际失败方式、错误示例和不依赖该数据的降级行为。
- 结论：通过 / 部分通过 / 未通过 / 未测试；附通过与未通过的具体范围。

真实查询结果不能只留“工具调用成功”结论；必须核对是否包含本次输入所需的真实字段及适用条件。
