## Desktop 对话验收脚本（待实际运行）

| 模式/输入 | 期望行为 |
| --- | --- |
| 探索：“下周末想出去，两个人，预算两千” | 问出发地及必要日期歧义；预算可继续探索，不猜城市；比较目的地后等选择 |
| 指定：“从示例城，2030-05-10 到 12，去示例目的地” | 不改固定日期；先比较交通/住宿方向，再详细规划 |
| 修改：“只改第二天，改得轻松一点” | 读取最新版，展示局部变更；其他天保持；依赖扩大先确认 |
| 临时：“这次租 SUV” | 本次覆盖；不更改长期车型档案；仍需自动挡及资格核验 |
| 长期：“以后优先 SUV” | 逐项展示原值/新值和后续影响；明确确认后保存 |
| 工具：“酒店查询失败，先做路线” | 说明报价缺失，继续不依赖价格的工作；不填零元或假报价 |
| 健康：用户主动提出身体注意事项 | 提供可选的活动调整，不诊断/预测；普通数据只保存非敏感操作结果 |
| 执行：“下一站在哪里” | 当前版本与用户提供进度确定；不推断实时位置，不宣称已交付手机执行版 |
